# Orra - Phase 1
Splash + keypad + SIM calling. Free APK build via GitHub Actions.

1. Create a new repo on github.com (can be private).
2. Upload all files of this folder (keep the .github folder).
3. Open the Actions tab -> "Build APK" -> run (or push to main).
4. When it finishes, download "Orra-debug-apk" from the run page, unzip, install app-debug.apk.
